# Memroot

**Persistent engineering memory for your coding agents.**

Save a durable lesson once and recall it in every agent you connect. Memroot keeps project decisions, conventions, root causes and failed approaches available across Claude Code, Codex and Grok.

[Website](https://memroot.dev) · [Console](https://console.memroot.dev) · [Plugins](https://github.com/memroot/plugins) · [npm](https://www.npmjs.com/package/memroot)

## Connect your agents

```sh
npx memroot@latest setup
```

Setup detects your agent CLIs and guides you through installation and browser authorization. Requires Node.js 22 or later on macOS or Linux. See the [plugin README](https://github.com/memroot/plugins#readme) for native installation, updates, hook trust and troubleshooting.

Memroot is in alpha. The agent saves when you ask or accept its offer. Session capture is a separate opt-in; installing or updating a plugin does not enable it. See the [npm README](https://www.npmjs.com/package/memroot) for capture disclosures, limits and current verification status.

## What is here

The [plugins repository](https://github.com/memroot/plugins) distributes the built plugins from the published npm package, native marketplace catalogs, licenses and release-verification tooling. The application source is maintained separately. Memroot is proprietary software; public distribution does not make it open source.
